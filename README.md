# Sofá

App Android que junta Netflix, HBO Max, Disney+ y Prime Video en un solo sitio:

- **Explorar**: elige un género (Animación, Crimen, Peleas, Terror…) y salen todas las pelis o series de ese género de todas tus plataformas juntas, con la etiqueta de dónde está cada una. Ordenable por populares, mejor valoradas o recientes.
- **Buscar**: dice en cuál de tus plataformas está una peli o serie (en España) y la abre en la app correcta.
- **Mi lista**: pendientes comunes, guardados en el móvil.
- **Apps**: lanzador de las cuatro apps.

Los vídeos se ven en las apps oficiales con tu cuenta; Sofá solo busca y te lleva.

## Cómo conseguir el APK

1. Crea un repositorio nuevo en GitHub (por ejemplo `sofa`).
2. Sube todo el contenido de esta carpeta (incluida la carpeta `.github`).
3. Ve a la pestaña **Actions**: se compila solo en unos 3-4 minutos.
4. Descarga `Sofa.apk` desde **Releases** (en la portada del repo, a la derecha) e instálalo en el móvil.

## Primera vez

La app pide una clave gratuita de TMDB:
themoviedb.org → crea cuenta → Ajustes → API → solicita una clave (uso personal) → copia la «Clave de la API».

Datos de TMDB y disponibilidad por JustWatch. Este producto usa la API de TMDB pero no está respaldado ni certificado por TMDB.
